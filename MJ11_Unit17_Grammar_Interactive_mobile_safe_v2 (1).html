From too / either to so / neither

We already know how to say “same!” with too and either. Now we can say it in a shorter way with so and neither.

Positive → SO

Mandy is a teacher.
Ross is, too.
→ So is Ross.
Mandy likes red.
Ross does, too.
→ So does Ross.
Mandy ate pizza.
Ross did, too.
→ So did Ross.

Negative → NEITHER

Mandy isn't a kid.
Ross isn't, either.
→ Neither is Ross.
Mandy doesn't like red.
Ross doesn't, either.
→ Neither does Ross.
Mandy didn't go to work.
Ross didn't, either.
→ Neither did Ross.
SO = positive same idea　 NEITHER = negative same idea　 is / does / did must match the first sentence.

Build the Pattern

Two magic patterns

Positive sentence
So + helping verb + subject.
Kelly is visiting a website.
So is Paul.
Negative sentence
Neither + helping verb + subject.
Grandpa can't send messages.
Neither can Grandma.
⭐ First ask: Is the first sentence positive or negative?
Mandy didn't go to school yesterday.
Jimmy didn't, either. → Neither did Jimmy.
