Review Unit 16 → New Grammar in Unit 17

From too / either to so / neither

We already know how to say “same!” with too and either. Now we can say it in a shorter way with so and neither.

Positive → SO

Mandy is a teacher.
Ross is, too.
→ So is Ross.
Mandy likes red.
Ross does, too.
→ So does Ross.
Mandy ate pizza.
Ross did, too.
→ So did Ross.

Negative → NEITHER

Mandy isn't a kid.
Ross isn't, either.
→ Neither is Ross.
Mandy doesn't like red.
Ross doesn't, either.
→ Neither does Ross.
Mandy didn't go to work.
Ross didn't, either.
→ Neither did Ross.

Build the Pattern

Two magic patterns

Positive sentence
So + helping verb + subject.
Mandy is a teacher.
So is Ross.
Mandy likes red.
So does Ross.
Mandy ate pizza.
So did Ross.
Negative sentence
Neither + helping verb + subject.
Mandy isn't a kid.
Neither is Ross.
Mandy doesn't like red.
Neither does Ross.
Mandy didn't go to work.
Neither did Ross.
