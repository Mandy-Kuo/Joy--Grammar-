# Joy--Grammar

## Fixed lesson-page rules

- Lessons are teacher-operated and projected for elementary students for about 12–15 minutes.
- Build from all supplied textbook, workbook, homework, and quiz pages.
- Follow this order: concept, teacher model, guided fill-in, speaking, rewrite or mixed practice, then two new independent questions.
- Put every revealed answer below its question and show it only when the teacher presses the answer button.
- Every question requiring students to produce a full spoken or written answer must include a long response line before the revealed answer.
- Color-code each revealed answer to match the grammar colors used in the model, so students can see the answer structure.
- Multiple-choice and word-reading pages do not need response lines.
- Units that are multiples of five are review units and do not need separate grammar pages.
